# 👑 KingLift.us — Official Brand Product Catalog & Web Platform

> Official direct-brand website and machinery showcase for **KingLift™ Heavy-Duty Material Handling & Lifting Solutions**.

---

## 🛠️ Tech Stack & Framework
- **Core:** React 19 + TypeScript + [Vite](https://vitejs.dev) (Google AI Studio compatible template)
- **Styling:** Tailwind CSS v4 + Custom Industrial Design Tokens
- **Icons:** Lucide React
- **AI Integration:** `@google/genai` (Google AI Studio Gemini 2.5 Flash SDK)
- **Feedback & Interactions:** Canvas Confetti + Smooth Modals/Drawers

---

## 🚀 Quick Start

```bash
# 1. Install dependencies
npm install

# 2. Run local development server
npm run dev

# 3. Build & validate for production
npm run build

# 4. Preview production build
npm run preview
```
